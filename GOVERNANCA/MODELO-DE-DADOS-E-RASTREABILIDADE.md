# MODELO DE DADOS E RASTREABILIDADE

> Projeto: Curioso da Internet IA | Documento: Modelo de Dados e Rastreabilidade | Versão: 1.0 | Data: 2026-10-08 | Status: ATIVO

Registro mínimo: ID; título; captura; data/período do fato; tema/subtema; entidades; descrição; fatos; causas/consequências; fontes; datas das fontes; verificação; confiança; palavras-chave; relações; hooks; ideias derivadas; formatos; última revisão.

Proveniência: CONTEÚDO → ROTEIRO → HISTÓRIA → CONHECIMENTO → PESQUISA → FONTE/EVIDÊNCIA.

Fluxo de reutilização: CONHECIMENTO → CONEXÕES → IDEIAS → HISTÓRIAS → CONTEÚDOS.

IDs devem ser estáveis. Correções registram ID, versão anterior, nova versão, data, motivo, fonte da correção e impacto nos derivados. Conteúdo temporalmente sensível guarda a última verificação.
