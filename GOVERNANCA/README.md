# GOVERNANÇA — Curioso da Internet IA

> Projeto: Curioso da Internet IA | Documento: Governança do Projeto | Versão: 1.0 | Data: 2026-10-08 | Status: ATIVO | Repositório: carlos-andrade/Curioso-da-Internet-IA

Esta pasta contém as regras permanentes que governam pesquisa, memória, produção editorial, validação, versionamento, publicação e evolução.

**Princípio:** GOVERNANÇA → PROMPT → PESQUISA → VALIDAÇÃO → CONHECIMENTO → STORYTELLING → ROTEIRO → DECUPAGEM → CONTEÚDO → PUBLICAÇÃO → MÉTRICAS → APRENDIZADO → ATUALIZAÇÃO.

Regras: toda regra permanente fica em /GOVERNANCA/; todo prompt fica em /PROMPT/; pesquisa preserva fontes, datas e verificação; fatos, interpretações, hipóteses e rumores são diferenciados; nada é inventado; informação temporal é revalidada; conhecimento novo é conectado ao existente; conteúdo publicado é rastreável; correções preservam histórico; adaptações respeitam cada plataforma; reconstruções/IA não são apresentadas como documentos reais; métricas orientam aprendizado sem alterar fatos; originalidade e transformação prevalecem.

Hierarquia: Governança = regras; Prompt = instruções; Fontes/Pesquisas = evidências; Conhecimento = informação consolidada; Histórias/Storytelling = narrativa; Roteiros/Decupagem = produção; Conteúdo = distribuição; Métricas = aprendizado; Arquivo = histórico.

Critério de qualidade: Fonte → Evidência → Verificação → Contexto → Narrativa → Originalidade → Adaptação → Rastreabilidade.
