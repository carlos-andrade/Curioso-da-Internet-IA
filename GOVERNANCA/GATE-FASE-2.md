# GATE FASE 2

## Objetivo

Definir o conjunto mínimo de verificações que deve passar antes da produção editorial em escala.

## Checklist determinístico

- [x] Fonte identificada.
- [x] Evidência identificada.
- [x] Afirmação vinculada à evidência.
- [x] Data/período do fato identificado.
- [x] Data de captura registrada.
- [x] Última verificação registrada quando aplicável.
- [x] Estado editorial compatível com a evidência.
- [x] Conflitos registrados.
- [x] IDs e referências válidos.
- [x] Proveniência completa para afirmações publicáveis.
- [x] Fato, interpretação, hipótese e boato separados.
- [x] Limitações explícitas.

## Critério

**APROVADO:** todos os itens aplicáveis passam.

**BLOQUEADO:** qualquer requisito obrigatório falha.

**CONDICIONAL:** há lacuna conhecida que não impede pesquisa adicional, mas impede promoção editorial.

## Princípio

A validação não determina “a verdade” por si só. Ela determina se o sistema possui evidência e rastreabilidade suficientes para sustentar o estado editorial atribuído.
