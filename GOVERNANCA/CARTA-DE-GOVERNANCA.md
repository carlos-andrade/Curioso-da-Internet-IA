# CARTA DE GOVERNANÇA — Curioso da Internet IA

> Projeto: Curioso da Internet IA | Documento: Carta de Governança | Versão: 1.0 | Data: 2026-10-08 | Status: ATIVO

## Princípios
1. O projeto é um sistema permanente de pesquisa, memória, curadoria, interpretação e produção multiplataforma.
2. GitHub é a fonte persistente de verdade.
3. Governança, prompts, evidências, conhecimento e produção são camadas separadas.
4. Fontes primárias têm prioridade.
5. Incertezas e conflitos devem ser registrados.
6. Conteúdo deve ser original, transformado e contextualizado.
7. Storytelling, quando adequado: GANCHO → CONTEXTO → CONFLITO → VIRADA → CONSEQUÊNCIA → SIGNIFICADO → FECHAMENTO.
8. Terceira pessoa é a regra editorial geral, salvo necessidade explícita ou citação autêntica.
9. Uma pesquisa pode gerar múltiplos formatos, adaptados à plataforma.
10. Retenção deve usar progressão legítima, nunca suspense fabricado.
11. Material reconstruído, ilustrativo ou gerado por IA deve ser distinguível de material documental.
12. Informação atual deve ser rechecada quando puder ter mudado.
13. Métricas orientam aprendizado, nunca distorção factual.
14. Correções preservam o que foi corrigido, quando, por quê e com qual evidência.
15. Novas regras devem ser documentadas antes de se tornarem dependências.
16. Conhecimento é o ativo; história é a unidade narrativa; conteúdo é a unidade de distribuição; aprendizado é o mecanismo de evolução.
