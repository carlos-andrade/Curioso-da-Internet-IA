# MODELO DE REGISTRO

Todo registro estruturado deve possuir, quando aplicável:

- ID único.
- Tipo de registro.
- Título.
- Estado.
- Data de criação.
- Data de atualização.
- Data de observação do fato.
- Fonte(s).
- Evidência(s).
- Entidade(s) relacionada(s).
- Afirmações sustentadas.
- Nível de confiança.
- Contradições.
- Relações com registros anteriores.
- Responsável pela validação.
- Histórico de alterações.

## Identidade
O ID é permanente. Alterações de conteúdo geram nova versão, não novo fato.

## Proveniência
Nenhuma afirmação pode ser promovida a conhecimento consolidado sem proveniência suficiente para o tipo de afirmação.
