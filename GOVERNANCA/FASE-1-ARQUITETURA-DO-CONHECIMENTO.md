# ARQUITETURA DO CONHECIMENTO

## Objetivo
Transformar o repositório em uma base de conhecimento editorial conectada, rastreável, versionada e reutilizável.

## Princípio central
A unidade principal do projeto é o conhecimento reutilizável, não o vídeo.

## Cadeia de proveniência
FONTE → EVIDÊNCIA → PESQUISA → CONHECIMENTO → CONEXÃO → HISTÓRIA → STORYTELLING → ROTEIRO → DECUPAGEM → CONTEÚDO → PUBLICAÇÃO → MÉTRICAS → APRENDIZADO.

## Regras
1. URL, documento ou testemunho é uma fonte; não é automaticamente uma evidência suficiente.
2. Toda afirmação relevante deve poder apontar para evidência.
3. Fato, interpretação, hipótese e rumor devem permanecer semanticamente separados.
4. Entidades devem possuir identidade reutilizável.
5. Conhecimento temporal deve registrar data de observação e necessidade de revalidação.
6. Contradições não devem ser apagadas; devem ser registradas e classificadas.
7. Correções preservam o histórico anterior.
8. Nenhum dado, fonte, citação ou relação pode ser inventado.
9. Conteúdo publicado deve apontar para a base de conhecimento que o sustentou.
10. Métricas podem alterar decisões editoriais, mas nunca reescrever fatos históricos.
