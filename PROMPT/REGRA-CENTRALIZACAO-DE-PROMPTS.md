# REGRA PERMANENTE — PASTA PROMPT

A pasta `/PROMPT/` é o único local oficial para armazenamento de prompts do projeto.

## Regra

Todo prompt criado ou modificado para o projeto deve ser salvo em `/PROMPT/`, incluindo:

- Prompt-Mestre;
- prompts especializados;
- prompts de pesquisa;
- prompts de curadoria;
- prompts de storytelling;
- prompts de geração de roteiros;
- prompts de decupagem;
- prompts de adaptação multiplataforma;
- prompts de validação;
- prompts de automação;
- prompts derivados do Prompt-Mestre;
- versões corrigidas ou ampliadas de prompts existentes.

## Proibição

Não criar prompts permanentes fora de `/PROMPT/`.

Outras pastas podem conter documentos, pesquisas, dados, histórias, roteiros, código e resultados produzidos pelos prompts, mas o prompt que orienta a produção deve permanecer em `/PROMPT/`.

## Versionamento

Toda alteração relevante de um prompt deve:

1. preservar a rastreabilidade;
2. indicar versão;
3. registrar data;
4. registrar objetivo da alteração;
5. evitar perda silenciosa da versão anterior.

## Fonte de verdade

O conteúdo salvo no repositório é a referência persistente do projeto. O chat não deve ser tratado como arquivo permanente de prompts.
