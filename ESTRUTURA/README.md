## Objetivo

Esta pasta registra a arquitetura estrutural adotada para transformar o projeto em uma base de conhecimento editorial conectada, versionada, rastreável e reutilizável.

A arquitetura não trata o vídeo como unidade principal. A unidade principal é o conhecimento reutilizável; a história é a unidade narrativa; o conteúdo é a unidade de distribuição.

## Princípio

REGRA → INSTRUÇÃO → FONTE → EVIDÊNCIA → PESQUISA → CONHECIMENTO → CONEXÃO → IDEIA → HISTÓRIA → STORYTELLING → ROTEIRO → DECUPAGEM → CONTEÚDO → PUBLICAÇÃO → MÉTRICAS → APRENDIZADO → ATUALIZAÇÃO

## Regra de implementação

A arquitetura deve ser implantada progressivamente. Primeiro são definidos modelos, estados, IDs, relações e validações; depois ocorre a ingestão em escala.

Não criar automação dependente de estruturas ainda não definidas.
