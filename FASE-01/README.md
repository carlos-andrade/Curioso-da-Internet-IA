# CURioso da Internet IA — FASE 01 — Arquitetura do Conhecimento

> **Histórico:** 2026-10-08  
> **Projeto:** Curioso da Internet IA  
> **Repositório oficial:** carlos-andrade/Curioso-da-Internet-IA  
> **Status:** Em implementação  
> **Princípio:** curiosidade é o ponto de partida; conhecimento é o destino.

## Objetivo

Definir o núcleo de dados que transforma pesquisa em conhecimento editorial reutilizável.

## Ordem normativa

`FONTE → EVIDÊNCIA → PESQUISA → CONHECIMENTO → ENTIDADE → CONEXÃO → IDEIA → GANCHO → HISTÓRIA → ROTEIRO → CONTEÚDO`

## Regras

1. Nenhuma afirmação relevante deve perder sua origem.
2. Fato, interpretação, hipótese e boato devem permanecer distinguíveis.
3. Um registro deve possuir ID estável.
4. Relações entre registros devem ser explícitas.
5. Informação contestada ou superada não deve ser apagada; deve ser versionada e marcada.
6. O sistema deve privilegiar reutilização do conhecimento, não produção isolada de vídeos.

## Entregáveis desta fase

- modelo de Fonte;
- modelo de Evidência;
- modelo de Pesquisa;
- modelo de Entidade;
- modelo de Conhecimento;
- modelo de Conexão;
- estados de validação;
- IDs e relações;
- banco inicial de ideias e ganchos;
- critérios para validação automatizada.

## Não entra nesta fase

Produção em escala, automação editorial completa, métricas de audiência e publicação automatizada.
