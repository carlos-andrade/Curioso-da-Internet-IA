# Curioso-da-Internet-IA

Sistema editorial de investigação, memória e produção de histórias.

## Princípio

**Curiosidade é o ponto de partida. Conhecimento é o destino.**

## Arquitetura vigente

GOVERNANÇA → PROMPT → FONTE → EVIDÊNCIA → PESQUISA → CONHECIMENTO → ENTIDADE → CONEXÃO → HISTÓRIA → STORYTELLING → ROTEIRO → DECUPAGEM → CONTEÚDO → PUBLICAÇÃO → MÉTRICAS → APRENDIZADO.

## Estado do projeto

- FASE 0 — Fundação: CONCLUÍDA.
- FASE 1 — Arquitetura do conhecimento: EM IMPLEMENTAÇÃO.
- FASE 2 — Validação: PENDENTE.
- FASE 3 — Produção: PENDENTE.
- FASE 4 — Automação: PENDENTE.
- FASE 5 — Publicação e aprendizado: PENDENTE.
- FASE 6 — Sistema editorial contínuo: PENDENTE.

## Regra de ouro

Nenhum resultado de pesquisa deve permanecer apenas no chat. O conhecimento operacional do projeto deve ser materializado e versionado no repositório.

## Governança

A autoridade documental segue:

PROMPT → CARTA → LAYOUT ÚNICO → CÓDIGO.

## FASE 1

A primeira implementação separa fonte de evidência, introduz entidades e conexões reutilizáveis, define estados de validação e estabelece a unidade de conhecimento como elemento central do sistema.

## Qualidade

Fonte → Evidência → Verificação → Contexto → Narrativa → Originalidade → Adaptação → Rastreabilidade.
